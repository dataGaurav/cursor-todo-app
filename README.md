# Tip Calculator

A lightweight web app for calculating the tip, total bill, and per-person share for a restaurant bill.

## Features

- Enter a bill amount
- Choose a preset tip percentage or custom tip
- Set the number of people splitting the bill
- View the tip amount, total, and per-person payment
- Reset the form with one click

## Project Structure

- `index.html` — app markup, styling, and JavaScript logic

## Run the App

Because this is a static HTML project, you can run it in any browser:

1. Open `index.html` directly in your browser, or
2. Serve it locally from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- No dependencies or build tools are required.
- The app uses browser-native JavaScript and modern CSS.
